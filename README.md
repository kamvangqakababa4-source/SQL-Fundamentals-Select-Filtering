# SQL Fundamentals: SELECT & Filtering

## 📌 Description

This project contains basic SQL exercises focused on retrieving and filtering data using the `SELECT` statement.

## 🎯 What is Covered

* Selecting all or specific columns
* Filtering data using `WHERE`
* Using conditions (`AND`, `OR`)
* Working with operators (`=`, `>`, `<`, etc.)
* Pattern matching with `LIKE`
* Sorting results using `ORDER BY`

## 📂 Files

* `SQL Fundamentals Q.sql` – contains all queries for the exercise

## 🚀 Purpose

The goal of this exercise is to build a strong foundation in SQL by practicing how to extract meaningful data from a database.
